# Чат с агентом ЛЛМ

## Описание

Этот проект предоставляет веб-интерфейс для чата с агентом ЛЛМ (Language Model Agent) с поддержкой Markdown и MathJax для рендеринга математических формул. Проект упакован в Docker для удобного развертывания.

## Возможности

- **Веб-интерфейс**: Интуитивно понятный интерфейс для общения с агентом.
- **Поддержка Markdown**: Возможность форматирования текста с использованием Markdown.
- **Рендеринг формул**: Поддержка MathJax для отображения математических формул.
- **Docker**: Упаковка в Docker для легкого развертывания.

## Установка и запуск

### Требования

- Docker
- Docker Compose

### Запуск

#### Использование релизной версии (рекомендуется)

Для использования компонента в составе общей системы рекомендуется использовать готовый релизный Docker-образ:

```bash
docker pull ghcr.io/lifelong-learning-assisttant/web_ui_service:v001
```

#### Сборка собственной версии (для разработки)

Если вам необходимо внести изменения или собрать свой образ для разработки:

1. Клонируйте репозиторий:

```bash
git clone <repository-url>
cd web_ui_service
```

2. Соберите и запустите Docker-контейнеры:

```bash
docker-compose up --build
```

3. Откройте веб-интерфейс в браузере:

```
http://localhost:8150
```

### Остановка

Для остановки контейнеров выполните:

```bash
docker-compose down
```

### Подробная информация

Более подробная информация о развертывании, включая различия между development и production режимами, доступна в [документации по развертыванию](docs/docker_deployment.md).

## Использование

1. Введите сообщение в поле ввода.
2. Нажмите кнопку "Отправить", чтобы отправить сообщение агенту.
3. Агент ответит на ваше сообщение.

## Примеры

### Отправка сообщения с формулами

Вы можете отправлять сообщения с математическими формулами, используя двойные знаки доллара для обозначения формул:

```
Решим уравнение $$x^2 = 4$$ → $$x = \pm 2$$
```

### Отправка сообщения с Markdown

Вы можете использовать Markdown для форматирования текста:

```
**Жирный текст**

*Курсивный текст*

- Список
- Элементов
```
