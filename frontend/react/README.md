# React Frontend для Learning Assistant

Современный фронтенд на React + TypeScript с Material-UI для Web UI сервиса.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
cd web_ui_service/frontend-react
npm install
```

### Разработка
```bash
npm run dev
```

Приложение будет доступно на `http://localhost:5173`

### Сборка для продакшена
```bash
npm run build
```

## 📁 Структура проекта

```
frontend-react/
```

## 🎯 Возможности

### Основные функции:
- **Чат-интерфейс**: История сообщений, поддержка LaTeX, подсветка кода
- **Загрузка файлов**: PDF, DOC, TXT файлы
- **Генерация тестов**: Создание заданий для самопроверки
- **RAG-поиск**: Умный поиск по контексту
- **Веб-поиск**: Дополнительная информация из интернета
- **Telegram-интеграция**: Работа с сообщениями из Telegram

### Технологии:
- **React 18** + **TypeScript**
- **Material-UI** - компоненты и дизайн
- **Zustand** - управление состоянием
- **Axios** - HTTP запросы
- **React Katex** - рендеринг формул
- **React Syntax Highlighter** - подсветка кода
- **Framer Motion** - анимации

## 🔧 API Endpoints

Фронтенд взаимодействует с backend через следующие эндпоинты:

- `POST /api/chat` - Отправка сообщения
- `POST /api/action` - Выполнение действий
- `POST /api/upload` - Загрузка файлов

Backend должен быть запущен на `http://localhost:8000`

## 🐳 Docker

Для запуска в Docker создайте Dockerfile и docker-compose.yml в родительской директории.

## 📝 Настройки

В настройках можно включить/выключить:
- Рендеринг LaTeX формул
- Очистить историю чата
- Проверить статус системы

## 🔍 Отладка

При возникновении ошибок проверьте:
1. Backend сервер запущен на порту 8000
2. CORS настроен правильно
3. Все зависимости установлены
4. Порты не заняты
