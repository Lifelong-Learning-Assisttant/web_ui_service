NiceGUI

Рекомендую №1, если хочется один стек, один контейнер, один язык.

Что это

Python-фреймворк поверх FastAPI + Vue + Quasar

Вы пишете только Python

UI рендерится в браузере

WebSocket — из коробки

Отлично дружит с Markdown и KaTeX

Нужен веб-интерфейс для отображения переписки между агентом ЛЛМ и пользователем как бы в виде чата с сообщениями в виде маркдаун с поддержкой рендеринга формул.

По идее сервис будет представлен отдельным контейнером с fastApi, который будет принимать в себя сообщения от агента и пользователя и визуализировать их переписку.

На базе какого фреймворка это будет проще и удобнее всего реализовать?

```
from nicegui import ui

ui.markdown("""
### Чат с агентом 🤖

Пусть $f(x) = x^2 + 1$  
$$\int_0^1 x^2 dx = \\frac{1}{3}$$
""")

messages = ui.column()

def add_message(author, text):
    with messages:
        ui.markdown(f"**{author}:**\n\n{text}")

ui.button("Сообщение от агента", on_click=lambda:
    add_message("Agent", "Решим уравнение $x^2 = 4$ → $x = \\pm 2$")
)

ui.run()
```
