# Руководство по вводу формул в чате

В этом документе описано, как правильно вводить математические формулы в чате, чтобы они корректно отображались.

## Основные правила

1. **Inline-формулы** (внутри текста):
   - Используйте одиночные знаки доллара для обозначения формул внутри текста.
   - Пример: `Решение уравнения $x^2 = 4$ даёт $x = \pm 2$.`
   - Отобразится как: Решение уравнения x² = 4 даёт x = ±2.

2. **Блочные формулы** (отдельной строкой):
   - Используйте двойные знаки доллара для выделения формул в отдельный блок.
   - Пример:
     ```
     Решим уравнение:
     $$x^2 = 4$$
     Решение:
     $$x = \pm 2$$
     ```
   - Отобразится как отдельные блоки с формулами.

## Примеры использования

### Простые формулы
- **Inline**: `Площадь круга $S = \pi r^2$.`
- **Блочная**:
  ```
  $$S = \pi r^2$$
  ```

### Дроби
- **Inline**: `Дробь $\frac{1}{2}$`
- **Блочная**:
  ```
  $$\frac{1}{2}$$
  ```

### Интегралы
- **Inline**: `Интеграл $\int_0^1 x^2 dx$`
- **Блочная**:
  ```
  $$\int_0^1 x^2 dx = \frac{1}{3}$$
  ```

### Греческие буквы
- **Inline**: `Греческая буква $\alpha$`
- **Блочная**:
  ```
  $$\alpha, \beta, \gamma$$
  ```

## Советы

1. **Экранирование**: Если вам нужно отобразить знак доллара как текст, используйте обратный слеш: `\$`.
2. **Пробелы**: Не ставьте пробелы между знаками доллара и формулой. Например, `$ x^2 $` не будет работать корректно.
3. **Сложные формулы**: Для сложных формул лучше использовать блочный режим ($$...$$), чтобы они были более читаемыми.

## Пример сообщения

```
Привет! Давай решим уравнение $x^2 = 4$.

Решение:
$$x = \pm 2$$

Проверка:
Для $x = 2$: $2^2 = 4$ ✓
Для $x = -2$: $(-2)^2 = 4$ ✓
```

Этот текст будет корректно отображать формулы как inline, так и в блочном режиме.
