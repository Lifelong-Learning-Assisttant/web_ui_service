# Руководство по вводу формул

## Основные правила

Формулы в чате используют MathJax для рендеринга.

### Inline-формулы (внутри текста)

Используйте **одиночные знаки доллара**:

```
Решение уравнения $x^2 = 4$ даёт $x = \pm 2$.
```

Отображается: Решение уравнения x² = 4 даёт x = ±2.

### Блочные формулы (отдельной строкой)

Используйте **двойные знаки доллара**:

```
Решим уравнение:
$$x^2 = 4$$
Решение:
$$x = \pm 2$$
```

Отображается как отдельные блоки.

## Примеры

### Простые формулы

**Inline:** `Площадь круга $S = \pi r^2$.`  
**Блочная:**
```
$$S = \pi r^2$$
```

### Дроби

**Inline:** `Дробь $\frac{1}{2}$`  
**Блочная:**
```
$$\frac{1}{2}$$
```

### Интегралы

**Inline:** `Интеграл $\int_0^1 x^2 dx$`  
**Блочная:**
```
$$\int_0^1 x^2 dx = \frac{1}{3}$$
```

### Греческие буквы

**Inline:** `Греческая буква $\alpha$`  
**Блочная:**
```
$$\alpha, \beta, \gamma$$
```

### MSE (из тестов)

**Inline:** `MSE = $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$`  
**Блочная:**
```
$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$
```

### Линейная регрессия

**Inline:** `$y = wx + b$`  
**Блочная:**
```
$$y = wx + b$$
$$\nabla L = \frac{2}{n}X^T(Xw - y)$$
```

## Советы

1. **Экранирование**: Если нужно отобразить знак доллара как текст, используйте `\$`.
2. **Пробелы**: Не ставьте пробелы между знаками доллара и формулой:
   - ❌ `$ x^2 $` — неправильно
   - ✅ `$x^2$` — правильно
3. **Сложные формулы**: Для сложных формул лучше использовать блочный режим для читаемости.

## Пример сообщения

```
Привет! Давай решим уравнение $x^2 = 4$.

Решение:
$$x = \pm 2$$

Проверка:
Для $x = 2$: $2^2 = 4$ ✓
Для $x = -2$: $(-2)^2 = 4$ ✓
```

Этот текст корректно отобразит формулы как inline, так и в блочном режиме.
