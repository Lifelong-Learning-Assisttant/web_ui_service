# План обновления фронтенда: Neural Netrunner Interface

## 1. Обзор задачи
Цель — полная замена текущего интерфейса на Material UI на кастомный киберпанк-интерфейс, вдохновленный концепцией «Нетраннерской Деки». Система должна превратиться из обычного чата в высокотехнологичную среду обучения Deep Learning.

## 2. Технологический стек
- **Framework:** React + Vite
- **Styling:** Tailwind CSS (для быстрой верстки и кастомных утилит)
- **Animations:** Framer Motion (эффекты появления, глитчи, переходы)
- **State Management:** Zustand (существующий `appStore.ts` будет расширен)
- **Math Rendering:** KaTeX (быстрый рендеринг формул с поддержкой кастомных неоновых цветов)
- **Icons:** Material Symbols Outlined (в HUD-стилистике)

## 3. Архитектура компонентов

### UI Primitives (Атомы)
- `CyberButton`: Кнопка со скошенными углами (clip-path) и неоновым свечением.
- `CyberInput`: Поле ввода с нижней бирюзовой границей и мигающим курсором.
- `BeveledContainer`: Контейнер со скошенными углами для карточек и панелей.
- `NeonGlow`: Обертка для добавления эффектов свечения (Cyan/Lime/Red).
- `CyberFormula`: Компонент для рендеринга KaTeX с неоновой подсветкой.

### Layout (Основа)
- `MainLayout`: Глобальная сетка.
- `ActivityBar`: Левая узкая панель навигации (Chat, Theory, Algos, Profile).
- `StatusBar`: Нижняя полоса системной телеметрии (Docker, Health, Ping).
- `NetrunnerDeck`: Нижняя треть экрана (Terminal, AI_Sync, Preview).

## 4. Этапы реализации

### Этап 1: Инфраструктура и Базовый Layout
- Настройка Tailwind конфигурации (цвета: Deep Charcoal, Dark Onyx, Cyber Cyan, Lime Neon).
- Создание глобальных стилей для `clip-path` и `glassmorphism`.
- Реализация `MainLayout`, `ActivityBar` и `StatusBar`.
- **Результат:** Пустой, но стилизованный каркас приложения.

### Этап 2: Авторизация и Инициация
- Реализация страницы `Neural Entrance` (Login) на основе HTML-макета.
- Реализация экрана `Identity Selection` (выбор аватара).
- Интеграция с `user_service` для сохранения выбранного скина.
- **Результат:** Пользователь может войти в систему и выбрать персонажа.

### Этап 3: Модуль Neural Chat & Deck
- Реализация `Neural Chat Workspace`: лента сообщений в HUD-стиле.
- Реализация `NetrunnerDeck`: переключение режимов ввода и терминала.
- Интеграция KaTeX в режим `PREVIEW`.
- **Результат:** Полноценный чат с ИИ в новом дизайне.

### Этап 4: Модули Theory Sync & Algo Sim
- Реализация `Theory Sync Hub`: двухпанельный режим для квизов.
- Реализация `Code Simulation Lab`: IDE с вводом сложности алгоритмов.
- Визуализация `Neural Graph` на фоне.
- **Результат:** Все образовательные функции переведены на новый дизайн.

### Этап 5: Полировка и Финализация
- Добавление глитч-эффектов при переходах.
- Финальное тестирование WebSocket-событий.
- Обновление документации.

## 5. Визуальные спецификации
- **Цвета:** 
  - Background: `#0A0A0B`
  - Accent: `#00EAFF` (Cyan)
  - Success: `#A2FF00` (Lime)
- **Шрифты:** 
  - UI: `JetBrains Mono`
  - Headers: `Orbitron`
- **Границы:** Скошенные углы 15px через `clip-path`.
