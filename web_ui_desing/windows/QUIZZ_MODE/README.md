Концепция режима «Теоретическая Синхронизация» (Neural Theory Sync Hub) — это интерактивная среда для проверки знаний по Deep Learning, вдохновленная процессом «взлома» данных и нейронного обучения. Здесь «Нетраннерская Дека» адаптирована для работы с теоретическими выкладками и квизами.

1. Трёхзональная композиция экрана

Экран организован таким образом, чтобы пользователь мог одновременно изучать теорию, общаться с ИИ и вводить ответы.

    Header (Верхняя панель):
        Заголовок: QUIZZ с иконкой нейронной сети.
        Шкала прогресса (QUIZ EVALUATION PROGRESS): Горизонтальный сегментированный индикатор в верхней части экрана (например, UNIT 03 / 10). Текущий этап выделен ярким бирюзовым свечением, пройденные — лаймовым.
    Workspace (Центральная область): Разделена на две вертикальные панели.
        Слева (Sync Target): Карточка с текущим вопросом квиза. Она структурирована на зоны: GOAL (цель), CONCEPT (теория) и FORMULA (блок с красиво отрендеренным LaTeX).
        Справа (AI Assistant): Лента чата с ИИ-экзаменатором. Здесь ассистент дает пояснения к вопросу или реагирует на свободные сообщения пользователя.
    Background (Neural Graph): На заднем плане за всеми окнами плавает интерактивный Neural Graph. По мере того, как пользователь дает правильные ответы, узлы графа заполняются лаймовым свечением, визуализируя процесс «синхронизации знаний».

2. Нетраннерская Дека в режиме Теории

Нижняя панель (Hub) переключается между двумя ключевыми модулями:

    Вкладка [ANSWER_QUIZ] (Основная):
        Назначение: Официальный ответ на вопрос квиза.
        Интерфейс: Вкладки EDITOR (ввод LaTeX/текста) и PREVIEW (просмотр отрендеренной формулы перед отправкой).
        Кнопка отправки: Крупная кнопка SYNC ярко-лаймового цвета со стрелкой-шевроном.
    Вкладка [AI_SYNC] (Вспомогательная):
        Назначение: Свободное общение с ассистентом для уточнения деталей.
        Индикация: При переключении в этот режим кнопка отправки меняет цвет на бирюзовый (Cyan).

3. Механика LaTeX-рендеринга

Особое внимание уделено математическому контенту:

    Formula Blocks: Сложные выражения (градиенты, функции потерь, веса) отображаются в специальных темных блоках с бирюзовой неоновой подсветкой.
    Live Preview: При переключении на вкладку PREVIEW в Деке, введенный пользователем LaTeX-код мгновенно превращается в математическое изображение. Это критически важно, чтобы пользователь был уверен в корректности своего ответа перед «синхронизацией».

4. Системная Телеметрия (Status Bar)

Нижняя статус-строка остается неизменной для всех режимов, подтверждая целостность системы:

    DOCKER: python:3.12-slim (стабильное окружение).
    STATUS: HEALTH (активный чекап системы).
    AGENT CONTEXT WINDOW (над декой) — показывает, сколько сообщений помнит ИИ в текущей сессии квиза.

UX-фишка: При успешном ответе на вопрос экран квиза на мгновение «вспыхивает» лаймовым неоном, а в терминале деки пробегает строка SYNCHRONIZATION_COMPLETE: DATA_INTEGRITY_100%.

Эта концепция превращает обычное тестирование в захватывающий процесс «прошивки» знаний в нейронную сеть игрока.
