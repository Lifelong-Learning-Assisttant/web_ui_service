# Дизайн окна логина (Neural Entrance)

## 1. Визуальная концепция и Атмосфера

**Стиль:** Cyberpunk / High-Tech HUD (Heads-Up Display).

**Цветовая палитра:**
- **Background:** Глубокий антрацит/черный (`#0A0A0A`) с текстурной сеткой.
- **Primary:** Cyan (Бирюзовый неон) — для границ, основных кнопок и фоновых узлов.
- **Secondary:** Lime-Green (Лаймовый неон) — для статусных сообщений, линий связи графа и сканера.
- **Warning:** Soft Yellow (Желтый неон) — для информационных алертов (`IDENTITY_NOT_FOUND`).

**Шрифты:** Моноширинные (Monospaced), имитирующие код или терминал.

## 2. Фон: Interactive Neural Graph & Digital Rain

### Neural Graph
На заднем плане расположена динамическая 2D-сеть. Узлы (бирюзовые точки) соединены тонкими лаймовыми линиями.

**Поведение:** Реализован эффект «гравитации» — при движении мыши ближайшие узлы плавно притягиваются к курсору, создавая интерактивную «паутину».

### Digital Rain
В правой части экрана — две колонки вертикально бегущего текста (hex-коды, обрывки кода). Скорость умеренная, прозрачность текста — 30-40%, чтобы не отвлекать от формы.

## 3. Окно авторизации (Central Terminal)

**Форма:** Модальное окно со скошенными углами и тонкой бирюзовой неоновой обводкой.

### Блок сканера (CAM_04 [OFFLINE])
- **HUD-кольца:** В центре две концентрические окружности. Внешняя — сплошная, едва заметная. Внутренняя — пунктирная, медленно вращается вокруг оси.
- **Линия сканирования:** Горизонтальная лаймовая линия с эффектом размытия (glow), медленно перемещается вверх-вниз по области сканера.

### Индикаторы статуса
- `IDENTITY_NOT_FOUND`: Желтая рамка и текст по центру.
- `SCANNING_UNREGISTERED_SUBJECT`: Лаймовый текст, пульсирующий с частотой 1.5 сек.

## 4. Инпуты и Кнопки

### Поля ввода (NEURAL_ID, ACCESS_CODE)
Темные прямоугольники с бирюзовой нижней границей. Плейсхолдеры стилизованы под системные переменные (`@ER_REF_#`).

### Кнопка SYNC IDENTITY
- **Состояние покоя:** Заливка бирюзовым градиентом, черный текст.
- **Hover:** Усиление свечения (bloom), легкий глитч-эффект текста.
- **Click:** Анимация «импульса», расходящегося от кнопки по фоновому графу.

## 5. Нижний статус-бар

- **System Status:** Слева — `SYSTEM_STATUS: READY` с мигающим зеленым индикатором (Heartbeat).
- **Version:** Справа — версия системы (`V.3.0.1`), выполненная мелким серым шрифтом.

Это описание поможет разработчику правильно настроить слои (z-index), выбрать цвета и реализовать нужную динамику.
