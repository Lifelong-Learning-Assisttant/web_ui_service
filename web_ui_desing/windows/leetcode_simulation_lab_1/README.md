Концепция режима «Симуляция Интервью по Алгоритмам» (Code Simulation Lab) представляет собой наиболее сложный и функциональный интерфейс приложения. 

Здесь «Нетраннерская Дека» (Нижний хаб) работает в тесной связке с двумя вертикальными рабочими панелями, обеспечивая полный цикл: написание кода, общение с ИИ и проверку в Docker-окружении.

1. Вертикальное разделение: Workspace (Верхние 2/3 экрана)

Рабочая область разделена на две независимые панели, каждую из которых можно свернуть для максимального фокуса.

    Панель Редактора (Editor Panel - Слева):
        Функционал: Полноценная IDE с подсветкой синтаксиса Python.
        Метрики сложности: В верхней части расположены два интерактивных поля: TIME COMPLEXITY и SPACE COMPLEXITY. Пользователь должен вручную ввести ожидаемую O-нотацию (например, $O(log\ n)$), что подчеркивает образовательный характер симуляции.
        Управление: Кнопка RUN инициирует процесс сборки и запуска тестов в нижнем терминале.
    Панель ИИ-Ассистента (AI Interviewer - Справа):
        Роль: Здесь ЛЛМ выступает в роли интервьюера. Она комментирует код, указывает на логические ошибки и может давать подсказки.
        Стиль: Чат-лента с поддержкой формул LaTeX (например, для объяснения временной сложности). Сообщения ассистента имеют лаймовый акцент, сообщения пользователя (USER_ROOT) — бирюзовый.

2. Нетраннерская Дека: Мультимодальный Хаб (Нижняя 1/3 экрана)

В этом режиме дека становится универсальным переключателем между «вводом» и «выводом».

    Режим [TERMINAL] (Активен на скрине 17ef2a9c...):
        Суть: Это окно вывода (Output). Пользователь здесь ничего не пишет, он наблюдает за работой системы.
        Контент: CONSOLE_LOG в реальном времени. Мы видим процесс компиляции, инициализацию тестов и финальные статусы [PASS] или [FAIL].
        Эстетика: Чистый моноширинный шрифт, лаймовое свечение для успешных операций, имитация работы настоящего Docker-контейнера.
    Режим [AI_SYNC] (Активен на скрине 1eadefb3...):
        Суть: Это окно ввода (Input). Дека превращается в мощный терминал для набора текста.
        Функции: Вкладки EDITOR (для ввода) и PREVIEW (для моментальной визуализации формул или пояснений перед отправкой).
        Индикатор контекста: Полоса AGENT CONTEXT WINDOW напоминает пользователю, сколько информации ассистент держит в памяти.

3. Единство и Интерактивы

    Цветовая кодировка действий: Кнопка SEND COMMAND меняет оттенок в зависимости от контекста, но всегда остается главным элементом управления в нижнем правом углу.
    Docker Status Bar: Самая нижняя строка — это «фундамент» системы. Она подтверждает, что код выполняется не «в вакууме», а в конкретном образе python:3.12-slim с определенным временем выполнения (TESTS TIME).
    Анимации: Переключение между TERMINAL и AI_SYNC на деке должно ощущаться как переключение физического тумблера на хакерской консоли — с быстрой сменой контента и легким «цифровым» мерцанием.

Эта концепция делает «Деку» не просто полем ввода, а динамическим инструментом, который адаптируется под нужды нетраннера: когда нужно — это чат, когда нужно — суровая консоль разработчика.
