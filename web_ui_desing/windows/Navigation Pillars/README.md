Концепция «Унифицированной системы навигации» (Unified Navigation Icons) — это визуальный алфавит нашего приложения. Иконки не просто указывают на раздел, они символизируют различные подсистемы «Нетраннерской ОС».

1. Стилистика и Форм-фактор

    Стиль: Минималистичный HUD (Heads-Up Display). Каждая иконка построена на строгой пиксельной сетке с использованием тонких линий одинаковой толщины.
    Состояния (States):
        ACTIVE: Иконка окрашивается в ярко-бирюзовый неон (Cyan) и помещается в квадратную рамку с мягким внешним свечением (Bloom effect). Это создает акцент на том, в каком «модуле» сейчас находится сознание пользователя.
        INACTIVE: Иконка имеет нейтрально-серый цвет без свечения, не отвлекая от основного контента.

2. Семантика иконок (Roster)

Набор состоит из четырех базовых символов, расположенных в боковой панели (Activity Bar):

    [CHAT] (Иконка облака сообщений):
        Смысл: Подсистема прямой нейронной связи с ИИ-ассистентом.
        Дизайн: Скругленный прямоугольник с «хвостиком», символизирующий поток данных.
    [THEORY] (Иконка открытой книги):
        Смысл: Хаб синхронизации теоретических знаний и прохождения квизов.
        Дизайн: Стилизованная книга, напоминающая хранилище данных или «базу знаний».
    [ALGOS] (Иконка терминала):
        Смысл: Системная оболочка для разработки алгоритмов и работы в Docker-окружении.
        Дизайн: Символ командной строки >_ внутри квадратной рамки.
    [PROFILE] (Иконка личности):
        Смысл: Идентификатор нетраннера, доступ к досье и уровню синхронизации (XP).
        Дизайн: Стилизованный силуэт головы и плеч внутри круга, отсылающий к биометрическому сканированию.

3. Технические параметры для разработки

    Размер: 24x24 px (базовый глиф), помещенный в контейнер 48x48 px.
    Толщина линий: 1.5 - 2.0 px для четкости на любых экранах.
    Эффект свечения (Active): box-shadow: 0 0 15px rgba(0, 234, 255, 0.4); и filter: drop-shadow(0 0 5px #00EAFF);.
    Расположение: Вертикальный ряд в узкой левой панели с одинаковыми отступами между иконками.

Эти иконки — это «горячие клавиши» к основным функциям системы, которые всегда остаются под рукой и обеспечивают бесшовный переход между режимами.
