Концепция «Нетраннерской Деки» (Unified Command Hub) — это центральный элемент интерфейса, объединяющий ввод данных и вывод системной информации. Она вдохновлена терминалами IDE (как в VS Code) и переосмыслена в эстетике киберпанка.

1. Анатомия и Расположение

    Размещение: Панель занимает нижнюю 1/3 часть экрана и растягивается на всю его ширину.
    Структура: Темная полупрозрачная подложка с эффектом "стекла" (glassmorphism), обрамленная тонкой бирюзовой рамкой со скошенными углами.
    Сетки и HUD: Поверх панели наложен едва заметный паттерн из технических линеек и микро-текста (координаты, системные коды), создающий ощущение сложного оборудования.

2. Система Вкладок (Module Switching)

Слева в верхней части панели расположены переключатели режимов, стилизованные под модули деки:

    [TERMINAL] (Алгоритмы): Режим вывода логов.
        Контент: Моноширинный текст. Системные сообщения — белые, статус [PASS] — лаймовый неон, ошибки [FAIL/ERROR] — бирюзовый или красный.
    [AI_SYNC] (Чат / Квиз): Режим прямого диалога с ИИ.
        Контент: Поле ввода с поддержкой Markdown и LaTeX.
    [ANSWER_QUIZ] (Теория): Специализированный режим для отправки официального ответа.

Логика активации: При клике на вкладку происходит анимация «прогрузки» содержимого (горизонтальная линия развертки). Активная вкладка подсвечивается ярким бирюзовым боксом.
3. Область ввода (Neural Input Engine)

Когда активен режим ввода (AI_SYNC или ANSWER_QUIZ), дека делится на функциональные зоны:

    Tabs (EDITOR / PREVIEW):
        EDITOR: Режим написания текста/кода/LaTeX. Используется синтаксическая подсветка.
        PREVIEW: Режим мгновенной визуализации. Текст превращается в красиво отрендеренные формулы и блоки кода. Переключение между вкладками должно быть мгновенным (Zero Latency).
    Input Field: Темное поле с кастомизированным курсором (мигающий бирюзовый прямоугольник). Плейсхолдер: Draft neural command...
    Action Area (Кнопка отправки):
        Название: SEND COMMAND >
        Стиль: Крупная кнопка со скошенным краем.
        Цветовая кодировка: Лаймовый неон, если это ответ на квиз (режим ANSWER), и Бирюзовый неон, если это обычное сообщение в чат (режим TEXT).

4. Контекстное окно (Agent Context Window)

Прямо над областью ввода (или в ее верхней части) расположена статусная линия:

    Текст: AGENT CONTEXT WINDOW
    Индикатор: Сплошная неоновая линия, которая заполняется слева направо.
    Визуализация: Показывает заполнение памяти ЛЛМ (например, 20/100 сообщений). При достижении 80% линия начинает медленно пульсировать.

5. Нижний Статус-бар (System Telemetry)

Самая нижняя узкая полоса, которая «приклеена» к краю экрана:

    Docker Status: DOCKER: python:3.12-slim (бирюзовый, четкий шрифт).
    Health Check: STATUS: HEALTH (лаймовый пульсирующий индикатор).
    Performance: TESTS TIME: 42ms (обновляется после каждого запуска кода).

6. Взаимодействие (UX)

    Collapsibility: Дека должна иметь возможность сворачиваться в узкую полоску (только статус-бар), чтобы освободить место для рабочей области.
    Sound (Концептуально): При переключении вкладок — легкий «металлический» клик, при отправке команды — звук «цифрового разряда».

Эта «Дека» — сердце интерфейса. Она делает пользователя не просто учеником, а оператором сложной системы.
