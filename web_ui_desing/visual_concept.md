Этот Style & Technical Guide (Техническое руководство по стилю) послужит фундаментом для разработки вашего приложения. Оно объединяет все визуальные решения, которые мы выработали, в четкую систему спецификаций.

1. Цветовая палитра (Neon Protocol)

Основная идея — максимальный контраст между глубоким темным фоном и ярким неоновым свечением.
Назначение 	Цвет 	HEX 	Применение
Background 	Deep Charcoal 	#0A0A0B 	Основной фон приложения
Surface 	Dark Onyx 	#141416 	Плашки, карточки, панели (полупрозрачные)
Primary Accent 	Cyber Cyan 	#00EAFF 	Границы, активные иконки, заголовки USER_ID
Success / Logic 	Lime Neon 	#A2FF00 	Прогресс-бары, статус HEALTH, ответы ИИ
Warning / Alert 	Electric Yellow 	#FFD700 	Теги SYNC_ACTIVE, предупреждения ID_NOT_FOUND
Error / Crit 	Pulse Red 	#FF3131 	Ошибки компиляции, статус FAILED, низкий баланс
Inactive 	Neutral Gray 	#4A4A4A 	Неактивные иконки, второстепенный текст
2. Типографика (Neural Typeface)

Шрифты должны выглядеть как интерфейс высокотехнологичного терминала.

    Основной шрифт (UI): Roboto Mono или JetBrains Mono (моноширинный).
        Body: 14px, цвет — серый или белый с легкой прозрачностью (85%).
        Technical Stats: 12px, цвет — бирюзовый или лаймовый.
    Заголовки (Headers): Orbitron или Rajdhani (футуристичные).
        Level (LVL 42): 32px-48px, White, Bold Italic.
        Window Titles (CHAT, PROFILE): 18px, Cyan, Upper Case, Letter Spacing: 2px.

3. Стили границ и Рамки (HUD Geometry)

Ключевой элемент узнаваемости вашего интерфейса — это отсутствие прямых углов.

    Signature Borders:
        Толщина: 1px или 1.5px.
        Форма: Скошенные углы (Beveled corners) под 45 градусов.
        Свечение (Glow): drop-shadow(0 0 5px rgba(0, 234, 255, 0.5)) для бирюзовых рамок.
    Элементы ввода (Inputs):
        Нижняя подчеркивающая линия в 2px бирюзового цвета.
        Светящийся курсор-прямоугольник в поле EDITOR.

4. Спецификации элементов (Component Specs)
Нетраннерская Дека (Bottom Hub)

    Высота: 33vh (одна треть экрана).
    Прозрачность: Background Blur 10px (эффект матового стекла).
    Вкладки: Прямоугольные боксы с инверсией цвета при активации (черный текст на светящемся фоне).

Иконки (Activity Bar)

    Контейнер: 48x48 px.
    Активное состояние: Бирюзовый квадрат 40x40 px со скруглением 2px и иконкой внутри.

Статус-бар (Bottom Telemetry)

    Высота: 24px.
    Стиль: Сплошная черная полоса, текст выровнен по краям (Padding: 0 16px).

5. Эффекты и Анимация (Visual FX)

    Glow/Bloom: Использовать аккуратно, чтобы не «замыливать» текст.
    Scanning Line: Вертикальная лаймовая линия с прозрачностью 30%, движущаяся со скоростью 3 сек/цикл.
    Neural Graph: Тонкие линии (0.5px) с притяжением к курсору (реализация через Canvas или SVG).
    Glitch: Кратковременное (100ms) смещение цветовых каналов (RGB Split) при переключении между основными режимами навигации.
